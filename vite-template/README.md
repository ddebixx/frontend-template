# Vite template

Vite + React starter for this pack (React Compiler on). Standards: [`docs/frontend/INDEX.md`](../docs/frontend/INDEX.md).

```bash
npm install
npm run dev
npm run check
```

Edit `src/pages/App.tsx`. i18n: `i18next` + `react-i18next` with `src/messages/` + locale switcher. Shared scripts: `lint`, `format`, `typecheck`, `test`, `test:e2e`, `fallow`.
